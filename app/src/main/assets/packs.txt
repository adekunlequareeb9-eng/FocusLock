## Arabic grammar basics
Q: What are the three kinds of words (الكلمة)?
A: اسم، فعل، حرف
Q: What are the three cases (الإعراب) of a noun?
A: رفع، نصب، جر
Q: What is the sign of الرفع on a regular singular noun?
A: الضمة
Q: What is the sign of النصب on a regular singular noun?
A: الفتحة
Q: What is the sign of الجر on a regular singular noun?
A: الكسرة
Q: What case is the مبتدأ (subject of a nominal sentence) in?
A: مرفوع
Q: What case is the خبر (predicate) of a simple nominal sentence in?
A: مرفوع
Q: What case is the فاعل (doer of the verb) in?
A: مرفوع
Q: What case is the مفعول به (direct object) in?
A: منصوب
Q: What case is a noun right after a preposition (حرف جر) in?
A: مجرور
Q: What does a nominal sentence (الجملة الاسمية) begin with?
A: اسم
Q: What does a verbal sentence (الجملة الفعلية) begin with?
A: فعل
Q: What is the effect of إنّ on the sentence?
A: تنصب الاسم وترفع الخبر
Q: What is the effect of كان on the sentence?
A: ترفع الاسم وتنصب الخبر

## Programming concepts

A: A named place that stores a value
Q: What is a function?
A: A reusable block of code that does one job
Q: What is a parameter?
A: A named input a function declares
Q: What is an argument?
A: The actual value passed into a function
Q: What is a loop?
A: Code that repeats while a condition holds
Q: What is a conditional?
A: Code that runs only if a condition is true
Q: What is a boolean?
A: A value that is either true or false
Q: What is an algorithm?
A: Step-by-step instructions to solve a problem
Q: What is a bug?
A: A mistake in code that causes wrong behavior
Q: What is debugging?
A: Finding and fixing bugs
Q: What is a compiler?
A: Translates source code into machine code before it runs
Q: What is an interpreter?
A: Runs source code directly, line by line
Q: What is syntax?
A: The grammar rules of a language
Q: What is a string?
A: Text data
Q: What is an array or list?
A: An ordered collection of items
Q: What is a dictionary (map)?
A: A collection of key-value pairs
Q: What is recursion?
A: A function that calls itself
Q: What is a class?
A: A blueprint for creating objects
Q: What is an object?
A: An instance of a class
Q: What is a library?
A: Ready-made code you import and reuse
Q: What is an IDE?
A: An editor with tools for writing and running code
Q: What is a comment?
A: Text in code that the computer ignores
Q: What is an exception?
A: An error raised while the program runs
Q: What is scope?
A: The part of code where a name can be used
Q: What is a constant?
A: A value that should never change
Q: What is an integer?
A: A whole number
Q: What is a float?
A: A number with a decimal point
Q: What does DRY stand for?
A: Don't Repeat Yourself
Q: What is pseudocode?
A: A plain-language outline of an algorithm

Q: What does FIFO mean (a queue)?
A: First in, first out
